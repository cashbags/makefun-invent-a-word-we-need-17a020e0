A Node 22 program that writes one freshly coined English word and its
one-line definition to `/output/entry.txt`:

> wanderage: the blank moment of standing in a room, having forgotten why you came in.

One familiar root, "wander", wearing the productive suffix "-age" — the
same suffix as mileage and leakage. It names the doorway effect: walking
into a room and forgetting why you came in, a moment everyone has felt
that English has no word for.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
